# Audio Indonesia

Skill Codex untuk membuat narasi dan dialog berbahasa Indonesia dengan enam profil suara. Sintesis berjalan lokal di Mac Apple Silicon.

1. Unduh `audio-indonesia-lengkap.zip` dari [Releases](../../releases).
2. Ekstrak ZIP, lalu salin folder `.agents/skills/audio-indonesia` ke lokasi yang sama di proyek tujuan.
3. Buka chat Codex di proyek tersebut dan kirim prompt seperti contoh di bawah ini.

> $audio-indonesia Bacakan naskah.txt dengan suara data-quran-baba. Simpan sebagai audio/narasi.wav.
